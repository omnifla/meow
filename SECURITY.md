# Security Policy

## Supported versions

meow is pre-1.0. Only the latest commit on `main` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting instead: open the **Security** tab of this repository, click **Report a vulnerability**, and include steps to reproduce.

Reports are acknowledged within a few days, and fixes are released as soon as they are ready.

## Scope

Anything in this repository's code. Bugs in dependencies (wgpu, winit, taffy, cosmic-text) should be reported to those projects directly.
